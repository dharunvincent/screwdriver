# Changelog

## 1.1.0 (2026-10-25)

* New rule 12, Prove it works: run the code and show real results before saying done; reproduce bugs before fixing them
* New Step 4, Save work in two places: commit locally, push to GitHub, keep working locally if GitHub is down and push later
* Safety: never commit secrets, never force push or delete history without asking
* Report now says how the work was proven and where it is saved

## 1.0.0 (2026-10-18)

First release.

* 11 core rules, language neutral
* Guided and expert modes, saved per project in CLAUDE.md
* Self check on changed code before finishing
* Short report format, less than 4 lines unless a decision is needed
* Worked examples in references/rules-explained.md
