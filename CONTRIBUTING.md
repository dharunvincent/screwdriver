# Contributing to Screw Driver

Thanks for helping make Screw Driver better.

## Ground rules

1. **Keep SKILL.md short.** It loads into Claude's context on every coding task, so every line costs tokens. Put long examples in `references/`.
2. **Stay language neutral in SKILL.md.** Language specific notes go in `references/`.
3. **Use your own words.** Do not copy text or code from the book or any other copyrighted source.
4. **Plain English.** The skill is used by non coders too. Avoid jargon, or explain it in one line.

## How to contribute

1. Fork the repo and create a branch.
2. Make your change.
3. Test it: install your copy as a skill in Claude Code, ask Claude to build something small, and check that the rules and the report format are followed.
4. Open a pull request explaining what you changed and why.

## Ideas we'd love help with

* Language notes files, for example `references/lang-python.md`, showing each rule in that language
* Clearer examples for any rule
* Cases where a rule made code worse, so we can fix or narrow it
